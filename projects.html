LEARNING HUB · PROJECTS

Build, don't just read.

Projects are where concepts become engineering ability. Work from small focused builds toward one complete product. Every project should leave you with something you can run, inspect, explain, test and improve.

CAPSTONE · FULL-STACK

Learning Hub

Build a real learning platform using the same architecture you studied across the curriculum: React and Next.js UI, TypeScript, PostgreSQL, authenticated server flows, validation, testing, deployment and an optional AI learning feature.

  • Define the learner problem and smallest useful version.
  • Model courses, lessons, progress and users.
  • Build a vertical slice from UI → server → database → UI.
  • Add authentication, authorization and validation.
  • Test, deploy, observe and improve it with real evidence.

BEGINNER · MODULES 01–03

Responsive learner profile

Build a semantic, responsive page with accessible navigation, a profile form, client-side interactions and a small persistent state.

Skills: HTML · CSS · JavaScript · accessibility

INTERMEDIATE · MODULES 03–05

Learning dashboard

Build a JavaScript dashboard, then convert the model and state layer to TypeScript. Add loading, empty, error and persistence states.

Skills: DOM · async · TypeScript · data modelling

UI · MODULE 06

React component system

Create a small reusable component set with typed props, variants, controlled inputs, keyboard behaviour and clear component boundaries.

Skills: React · state · events · accessibility

FULL-STACK · MODULES 07–09

Course management app

Users can browse courses, view lessons, enroll, track progress and access only the resources they are authorized to use.

Skills: Next.js · PostgreSQL · APIs · auth

PRODUCTION · MODULE 10

Ship it safely

Take an existing app through threat modelling, performance measurement, automated testing, CI, deployment, logging and recovery drills.

Skills: security · performance · testing · operations

AI · MODULE 11

AI learning coach

Add one useful AI capability with server-side model access, validated structured output, authorization, evaluation cases and failure handling.

Skills: model APIs · RAG · tools · evaluation

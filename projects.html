LEARNING HUB · PROJECTS

Learn by reading real code.

This replaces the old simulator-style project area. Each project is a deliberately chosen full-stack build, with source code, architecture, concepts and an explanation of why the code exists.

How to use this: read the project explanation first, open the source files, follow the code from entry point to data boundary, then rebuild the project yourself. These examples are learning references; projects that require a database, payment provider or model API show the real application-side code and clearly identify the external boundary.

Understand → trace the code → rebuild → extend → ship

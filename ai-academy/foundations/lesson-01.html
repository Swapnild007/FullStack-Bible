What Is Computation?

AI engineering begins with a precise model of computation.

Core mental model

Model computation as state plus transition rules. Distinguish problem, algorithm, program and running process. Define inputs, outputs, invariants and termination.

Worked example

A model-serving request is a sequence of transformations: validate input → transform representation → compute prediction → postprocess → return output.

Implementation

function total(values): result = 0; for each value: result += value; return result

Engineering lab

Write the contract and invariant for a maximum or sum function. Trace empty, singleton and mixed inputs.

Mastery gate

Specify an algorithm before implementation and defend its termination and complexity.

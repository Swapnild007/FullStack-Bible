Python Execution Model

Understand what sits between Python source and runtime behavior.

Core mental model

A simplified path is source → parse/compile → bytecode → runtime execution. The exact details vary by Python implementation.

Worked example

Use disassembly as an observation tool, not as a substitute for the language model. Compare arithmetic and branching functions.

Implementation

import dis\n\ndef add(a, b):\n    return a + b\n\ndis.dis(add)

Engineering lab

Disassemble a small function, modify one operation and record what changed.

Mastery gate

Explain the roles of source, compiler, bytecode and runtime without claiming simplistic line-by-line interpretation.

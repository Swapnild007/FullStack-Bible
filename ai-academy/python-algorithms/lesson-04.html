Data Structures

Representation determines which operations are cheap and which algorithms are practical.

Core mental model

Study arrays, dynamic arrays, stacks, queues, sets, maps, trees and graphs through their supported operations.

Worked example

Membership in a hash set is expected O(1), while scanning a list is O(n). The right choice follows from workload requirements.

Implementation

Implement a stack and queue using basic Python structures, then analyze operations.

Engineering lab

Choose representations for a feature vocabulary, BFS frontier, cache and adjacency list.

Mastery gate

Select a structure from required operations and justify expected and worst-case behavior.

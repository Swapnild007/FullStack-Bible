# FullStack Bible

A connected technical knowledge system for learning and building full-stack software.

## Product model

**Knowledge → Learn → Visualize → Code Lab → Build → Master**

The Bible is intentionally not an essay collection or a generic LMS. Concepts are connected to mental models, visual explanations, runnable code, practice checkpoints and projects.

## Current baseline

- Web Foundations
- CSS & Styling
- JavaScript / Runtime
- React & Next.js
- Backend / APIs
- Databases
- Cloud & DevOps
- Systems & Architecture
- Event Loop lesson with visualization
- Runnable browser Code Lab
- Local notes and completion state
- Responsive desktop/mobile workspace

## Run

Open `index.html` in a modern browser. No build step is required for the current baseline.

## Engineering rule

This repository is the single source of truth. New work must preserve existing functionality and extend the system rather than replacing working features with disconnected prototypes.

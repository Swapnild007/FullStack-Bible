The Event Loop

Understand how JavaScript coordinates synchronous execution, asynchronous browser APIs, queues and the call stack. The Bible connects the mental model directly to runnable code.

The mental model

JavaScript executes one piece of work at a time. Async APIs can wait outside the call stack, then queue callbacks for later execution.

When the call stack is empty, the event loop can move queued work into execution.

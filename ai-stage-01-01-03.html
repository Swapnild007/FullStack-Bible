Bits, bytes & binary representation

Understand how information becomes machine-representable data.

FIRST PRINCIPLESWORKED EXAMPLEIMPLEMENTATIONMASTERY GATE

1. Why this matters

A bit represents one binary digit. A byte is conventionally eight bits. Larger values are represented by sequences of bits interpreted according to a representation scheme.

2. Formal model

For unsigned binary, positional notation uses powers of two. 1011₂ means 8 + 2 + 1 = 11. Representation is an encoding that gives a bit pattern meaning.

3. Worked example

13 = 8 + 4 + 1, so 13 is 1101₂. Conversely, 1101₂ evaluates to 13 under unsigned interpretation.

4. Implementation

The implementation is intentionally small so the underlying concept remains visible.

x = 13
print(bin(x))
print(x.to_bytes(2, 'big'))
print(int.from_bytes(b'\x00\r', 'big'))

5. Execution trace

The same bits can represent different values depending on interpretation. Signed integers, floating point, characters and files impose different rules.

6. Under the hood

AI systems ultimately store tensors, images, model files and network payloads as binary data. Quantization changes representation, range, precision and memory usage.

7. Complexity / engineering implications

Eight bits do not always mean the same numerical range; interpretation matters. Decimal and binary are representations of an abstract value, not competing values.

8. Failure modes & misconceptions

Convert 0–31 between decimal and binary. Inspect big-endian and little-endian byte order and explain why byte order matters.

9. Engineering lab

Explain bit, byte, representation and endianness, and why a byte sequence has meaning only under a format.

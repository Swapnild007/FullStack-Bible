What is computation?

Learn to model computation as state transformation under explicit rules.

FIRST PRINCIPLESWORKED EXAMPLEIMPLEMENTATIONMASTERY GATE

1. Why this matters

Computation is the systematic transformation of an input state into an output state. Stop thinking of a program only as English-like instructions; think about state, rules, representation and observable behavior.

2. Formal model

A useful model is S0 → T1 → S1 → T2 → ... → Sn. A deterministic computation applies a defined transformation to a state. An algorithm adds a finite procedure, defined inputs and outputs, and a termination expectation.

3. Worked example

A function that receives prices and returns a total repeatedly changes an accumulator state. If the specification does not define empty or invalid input, the computation is underspecified.

4. Implementation

The implementation is intentionally small so the underlying concept remains visible.

def total(values):
    acc = 0
    for value in values:
        acc += value
    return acc

print(total([10, 20, 5]))

5. Execution trace

acc starts at 0; after 10 it is 10; after 20 it is 30; after 5 it is 35. The loop implements repeated state transformation.

6. Under the hood

Python evaluates expressions, obtains objects, performs addition according to their types, binds the result to acc and repeats until the iterator is exhausted.

7. Complexity / engineering implications

One pass over n values gives O(n) time and O(1) additional accumulator space.

8. Failure modes & misconceptions

Failure: coding before defining inputs, outputs and invalid cases. Also do not confuse an algorithm with Python syntax.

9. Engineering lab

Write specifications for total, average and maximum before coding. Define valid input, output, empty-input behavior and complexity, then implement and test.

10. Mastery gate

Explain state, transformation, algorithm and program. Given a new problem, write its input, output, constraints, state transition and termination condition.
